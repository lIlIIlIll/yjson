# 2026-10-26 0.2.0 候选 Pure 测量：通过

## 测量条件

- Linux x86_64、Cangjie STS `1.2.0`、stdx `1.2.0.1`；两侧实际编译均为显式 `-O2`。
- 未加入 cjdoc 使用的 `--fno-chir-function-inlining`。本次不比较 SDK 版本或内联开关。
- `YJSON_PURE_DIRECT_V1`、`--gate-mode release --rounds 11 --rebuild --enforce`；工作量和阈值未改。
- `cjProcessorNum=1`、`cjHeapSize=128MB`；业务线程绑定 CPU 0，GC main/helper 绑定 CPU 1，GC pool/schmon 绑定 CPU 3。
- 测量前筛选空闲物理核，记录全部相关 SMT 线程的利用率。奇数轮 baseline 先运行，偶数轮 candidate 先运行。
- 每个进程只接受一条有效直接计时声明；核验调用数、预热、分段、所选测试成功状态、绑核和 RSS sidecar。

两侧都在清理后重新构建，源码与锁文件在构建前后保持不变。两个隔离快照使用相同 path
依赖 overlay 和宏源码；生产仓库保留真实 Git pin。源码身份不归一化版本或依赖 pin。
